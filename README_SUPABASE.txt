MYSTYLE + SUPABASE

1. Sube index.html a la raiz del repositorio MYSTYLE en GitHub.
2. En GitHub: Add file -> Upload files -> selecciona index.html -> Commit changes.
3. Abre https://edu69peral-bit.github.io/MYSTYLE/ y pulsa Ctrl+F5.
4. Pulsa ⚙ Administrar.
5. Inicia sesión con el usuario de Supabase que creaste.
6. Si Supabase está vacío y este navegador tiene productos guardados, la tienda ofrecerá migrarlos automáticamente.
7. Desde Administrar puedes agregar, editar, eliminar uno o seleccionar varios y usar "Eliminar seleccionados".
